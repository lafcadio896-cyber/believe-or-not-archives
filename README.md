# BELIEVE OR NOT ARCHIVES

「信じようと、信じまいと―」形式の短いネットロアを、すべてオリジナル創作として蓄積・公開するアーカイブです。

## 運用

- ChatGPTのスケジュールが定期的に新作を生成する
- 生成結果を `archive/` と `data/lores.json` に追加する
- GitHub Pagesで閲覧用サイトを公開する
- GitHub Actionsは文章生成には使わず、Pagesの配信だけを担当する

## 基本形式

- 冒頭と末尾は「信じようと、信じまいと―」
- 本文は原則4行、3〜6文
- 時代・地域・人物・記録などの具体性を持たせる
- 語り口は簡潔で客観的にする
- 怪異を説明し切らず、最後に事実関係のずれや未解決点を残す
- 実在の事件・被害者・存命人物を題材にした虚偽情報は作らない

## 注意

収録作品はフィクションです。実在の人物・団体・事件とは関係ありません。
